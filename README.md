One funny line of awkward small talk a robot says to another in an elevator, built for make.fun's ["Two Robots in an Elevator"](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty ($10 in USDC).

## The entry

> The doors bounced off my arm and I reflexively said "sorry" to them, and my lidar confirms you saw the whole thing.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt` when set). Python 3.13 standard library only.
